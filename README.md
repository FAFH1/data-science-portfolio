# Data Science Portfolio

This repository contains the GitHub Pages source for Kejia He's data science
portfolio. The site is built from `index.md` using a lightweight Jekyll layout.

## Contents

- `index.md` — portfolio homepage
- `_layouts/default.html` — shared page layout
- `assets/style.css` — responsive site styling
- `images/` — project visualizations
- `_config.yml` — GitHub Pages configuration

## Featured project

[Iris Species: Measurement Patterns and a Reproducible Classification Baseline](https://github.com/FAFH1/data-science-project)

The project analyzes 150 Iris flowers and evaluates a standardized
nearest-centroid classifier, which achieves 80% accuracy on a deterministic
hold-out test set.

## Publishing

The site is published with GitHub Pages from the `main` branch and the repository
root folder.
